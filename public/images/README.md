# Portfolio photographs

Add your real photographs here; no stock or generated photos are included.

- `profile.jpg`: square professional portrait, ideally at least 500 × 500 pixels.
- `hero/hero-1.jpg` through `hero/hero-8.jpg`: technical events, teams, hackathons, or personal photographs.

The Hero uses object-fit: cover, so edges can be cropped. Missing or failed images retain the intentional navy pattern/initials fallback. Reload after adding files.

Social destinations are configured in `src/data/portfolio.ts`. Replace the null values with real HTTPS profile URLs and a `mailto:` address. Unconfigured social icons are visibly marked as coming soon and do not navigate.
